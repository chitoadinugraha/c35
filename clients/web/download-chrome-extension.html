Alien AI Home

Chrome extension (daily profile)

Remote your default Chrome with saved logins — for sites that block automated browsers. Requires Windows desktop Chrome and the Alien AI app to pair.

1. Native host + browser agent

Install alienai_remote_browser and register the native messaging host com.alienai.c35.remote (included in the extension zip when published).

Download Windows remote agent

Or use the remote-browser OTA bundle when chrome-extension zip is published.

2. Load the extension

  1. Download chrome-extension.zip (when available).
  2. Unzip to a folder, e.g. %LOCALAPPDATA%\AlienAI\chrome_extension\.
  3. Open chrome://extensions → Developer mode → Load unpacked → select the folder with manifest.json.

3. Pair with Alien AI

Click Pair device in the extension popup. A tab opens with your code — or open the pair page after the host starts pairing.

In the app: Devices → Pair with code.

Troubleshooting

  • Native host not reachable — reinstall host manifest for your user; path must point to alienai_remote_browser.exe.
  • No video in app — ensure a WebRTC Remote session is open; capture runs only while viewing.
  • Policy installs — use updates.xml + packed .crx after publish.
