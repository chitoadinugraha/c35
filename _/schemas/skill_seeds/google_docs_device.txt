# Google Docs — edit & format on @device (eye + hand)

Use on **@device Windows Chrome** when the user wants a **Google Doc** (docs.google.com/document), not Alien `presentation.*` or bot APIs.

## Open or resume

1. `device.screenshot` (som=true) if unsure which tab is active.
2. Reuse an open Doc tab — do not open duplicate `docs.new` tabs.
3. Launch `https://docs.new` or `https://document.new` only when no Doc is visible.

## Typing & structure

- Click in the document canvas (not the title chip) before `type_text`.
- **Title**: click the document title at top; `click_and_type` the new title.
- **Headings**: select line → toolbar **Normal text** dropdown → Title / Heading 1 / Heading 2, or shortcut `ctrl+alt+1` / `ctrl+alt+2` (US layout).
- **Bold / italic / underline**: select text → toolbar or `ctrl+b` / `ctrl+i` / `ctrl+u`.
- **Bullets / numbering**: select lines → toolbar list icons or `ctrl+shift+8` / `ctrl+shift+7`.

## Alignment & spacing

- **Align**: select paragraph → toolbar align left/center/right.
- **Line spacing**: Format → Line & paragraph spacing (or toolbar line spacing).
- **Indent**: increase/decrease indent toolbar buttons.

## Tables & inserts

- Insert → Table for new tables; tab between cells.
- For simple tables, type row by row; verify column alignment in screenshot.

## Verification

Finish only when screenshot shows the requested title, headings, and body text. Do not claim success from intent alone.
