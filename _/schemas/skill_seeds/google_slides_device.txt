# Google Slides — edit & format on @device (eye + hand)

Use on **@device Windows Chrome** for **Google Slides** (`docs.google.com/presentation`). This is **not** Alien `presentation.create` (in-app deck builder).

## Open or resume

1. Screenshot first if tab state is unknown.
2. Reuse open Slides tab — avoid stacking multiple `slides.new` tabs.
3. Open `https://slides.new` only when no presentation tab exists.

## Slides & text

- **New slide**: toolbar `+` or `ctrl+m`.
- **Title / body**: click the placeholder box; `type_text` or `click_and_type`.
- **Select slide**: click thumbnail in left filmstrip.
- **Duplicate slide**: right-click thumbnail → Duplicate, or copy/paste slide.

## Formatting

- Select text box or text → **Bold** `ctrl+b`, **Italic** `ctrl+i`.
- **Font size**: toolbar dropdown or `ctrl+shift+>` / `ctrl+shift+<`.
- **Align text** in box: toolbar align buttons.
- **Theme**: right panel Themes — close with X (≈ x 0.956, y 0.266) when it blocks canvas.
- **Background / layout**: Slide → Change background; Layout picker on toolbar.

## Images & shapes

- Insert → Image → upload or URL when user provides asset.
- Insert → Shape for simple diagrams; verify placement in screenshot.

## Verification

Confirm slide count, titles, and visible text in the latest `device.screenshot` (som=true) before reporting done.
